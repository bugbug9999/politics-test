# 정치성향 테스트 이미지 폴더

여기에 PNG를 넣으면 결과 카드에 **자동으로** 일러스트가 적용됩니다. (없으면 이모지로 폴백)

## 파일명 규칙 (= 유형 ID)
`app/test/IMAGE_PROMPTS.md`의 프롬프트로 생성한 이미지를 아래 이름으로 저장:

### 진영형 16종 (4글자 코드)
`JGLS.png` `JGLO.png` `JGMS.png` `JGMO.png` `JCLS.png` `JCLO.png` `JCMS.png` `JCMO.png`
`BGLS.png` `BGLO.png` `BGMS.png` `BGMO.png` `BCLS.png` `BCLO.png` `BCMS.png` `BCMO.png`

### 중도 4종
`JUDGE.png` `IGNORANT.png` `BOTHSIDES.png` `APATHY.png`

### (선택) 커버/OG
`cover.png` `og.png`

## 권장 규격
- 정사각 `1:1`, 512×512 이상, 투명 배경 또는 진영색 배경
- 결과 카드에서 160×160으로 표시됨(고DPI 대비 2배 권장)
